# 64dao: дополнение «Мультиконтурная диагностика, маршруты, AI, динамика»

Версия 1.0 · 2026-07-20 · Утверждено владельцем методологии (Подласов Д.С.)
Назначение: мастер-документ дополнения + промпт для AI-исполнителя в репозитории `Dmitry-pixel/64dao`.
Вне скоупа этого дополнения: роадмап 4.1+4.2 (консультация-апсейл, freemium) и доработка главной страницы — отдельная задача.

## 2. Сводный порядок работ и зависимости

```
A. Контуры          ── этапы A1–A7 (см. план) ──┐  A1 (миграция 009) — первый и самый
                                                 │  рискованный этап всего дополнения
B. Маршрут          ── после A5 (рендер секций) ─┤
C. Метод 2          ── после A2 (обобщение       │  скоринга); контент утверждён,
                        C-этапы можно вести      │  параллельно B
D. AI-чат           ── независим; полный контекст │  требует A (снимки контуров),
                        включение флага — после   │  правовых документов и теста
                        провайдеров               │
E. Динамика/подписка ── E1 (companies) независим; │  расчёты динамики — после A;
                        онлайн-продажа — после    │  production-готовности платежей
F. Чек-листы        ── после B и E ──────────────┘
```

Рекомендуемая очередь для одного исполнителя: **A1 → A2 → C1 → A3–A5 → B → A6 (контент контуров) → E1–E4 → F → C2–C5 → D → E5–E7**. Допустима параллелизация D и E1 с любым моментом после A2.

Сквозные блокеры (не создаются этим дополнением, но ограничивают включение фич):
- Платёжный контур: `verify_webhook()` — заглушка, фискализация неполная, refund нет → онлайн-продажа подписки (E5) и `ENFORCE_CREDITS` заблокированы до устранения.
- Правовые документы: оферта/политика ПДн требуют дополнений для AI-чата (хранение диалогов) и подписки (услуга периода) до включения флагов.

## 4. Контент и решения владельца (справочно для исполнителя)

- Опросники контуров (A) — **утверждены** (версия 1.0, 2026-07-20): 24 утверждения × 3 контура, реверсивные 1.3/2.3/3.3/4.4/5.3/6.3, вето 4.1. Названия контуров: «Финансовая функция», «Продукт/Сервис», «Рынок и продажи», «Операционные процессы».
- Опросник Метода 2 (C) — черновик 54 утверждений готов; статус утверждения уточнить у владельца перед этапом C5 (контент). Реверсивные — позиция 2b во всех блоках.
- `fin_pattern_*` заполнены для всех 64 стратегий (проверено по БД 2026-07-20) — маршруты и парные гексаграммы получают контент без заглушек.
- 16 текстов kind `trigram` — владелец отредактирует после реализации C3 (когда увидит их в отчёте); плейсхолдеры не блокируют.
- Подписка: разовый платёж за период (12 мес по умолчанию), на аккаунт пользователя, ручное продление, админ-выдача до готовности платежей.
- AI: провайдер российский (YandexGPT/GigaChat), выбор по тесту; лимит 25 сообщений на отчёт; включено в оплаченный отчёт.

## 5. Порядок приёмки владельцем

1. После A1 (миграция) — сверка счётчиков finance-данных, регресс финансового флоу на проде.
2. После A5 — просмотр PDF с 2 и 4 контурами (вёрстка сводной карты).
3. После B — просмотр маршрутов на 2–3 реальных отчётах.
4. После C3 — ревизия текстов триграмм в контексте BMC-отчёта.
5. Перед D-включением — сравнительный тест провайдеров (10–15 отчётов, рубрика в плане D §7).
6. После E4 — прогон динамики на тестовой компании с 2–3 диагностиками.
7. Перед E5 и включением любых продаж — правовые документы + производственная готовность Точки.
